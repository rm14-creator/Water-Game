# Water Game

Unity project source repository. Initial implementation: **Character Showcase** prototype with three idle activity loops per character, outfit switching, and Fixed/Orbit/Close-up cameras.

The initial repository contains a standalone importable feature under `Assets/WaterGame/CharacterShowcase`. The generated demo uses neutral greybox placeholders; **no final character models, canonical outfits, or animation assets are included**.

## Try the demo

1. Create/open a Unity 6.6 project (3D URP recommended; the showcase runs alongside the 2D strategic game).
2. Copy/merge the repository's `Assets/WaterGame/CharacterShowcase/` folder into `Assets/`.
3. In the Unity menu select **Tools → Water Game → Create Character Showcase Demo**.
4. Open `Assets/WaterGame/CharacterShowcase/Demo/CharacterShowcaseDemo.unity` and press Play.

See `Assets/WaterGame/CharacterShowcase/README.md` for authoring and production guidance.
